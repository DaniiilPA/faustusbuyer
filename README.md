# FaustusAutoBuyer — Авто-выкуп через витрину Фостуса (Path of Exile)

Автономная связка для моментального выкупа предметов по кнопке **«Travel to Hideout»** из Merchant Tab продавца с двухуровневой верификацией и защитой от скама.

---

## 🚀 Как это работает

1. **В браузере:** На `pathofexile.com/trade` (или `pathofexile.com/trade2`) включен **Live Search**.
   - Скрипт Tampermonkey (v1.3) извлекает название целевого предмета и копирует метку цели в буфер обмена (`FAUSTUS_TARGET:ItemName`) через привилегированный API `GM_setClipboard` (надежно работает даже из фоновой вкладки браузера).
   - Кликает кнопку `Travel to Hideout` с рандомизированной задержкой человека (60–180 мс).
   - Включает 15-секундный кулдаун от спама других лотов.
2. **В игре:** Игра сама телепортирует персонажа в убежище продавца и автоматически открывает витрину Фостуса с подсвеченным предметом.
3. **В ExileApi:** Плагин `FaustusBuyer`:
   - Принудительно выводит окно игры на передний план (`EnsureForeground` с `AttachThreadInput`);
   - Считывает цель из буфера обмена и ищет в витрине предмет **с совпадающим уникальным именем, базой или редким названием**;
   - Если имя не передано — использует нативную рамку подсветки игры (`HighlightBorder`);
   - Если товар в витрине **не совпал** с тем, за чем летели — отменяет покупку и летит домой (защита от скама);
   - Выжидает рандомизированную паузу реакции (120–260 мс) и делает `Ctrl + Click` по предмету;
   - Если выскакивает окно подтверждения цены («Confirm Purchase»), автоматически нажимает кнопку подтверждения;
   - Закрывает окно (`Escape`) и отправляет `/hideout` для возврата домой (через буфер обмена, без сбоев при русской раскладке Windows).

## 🛡 Обработка Edge Cases (Защита от сбоев)

- **Фоновые вкладки браузера:** Tampermonkey использует `GM_setClipboard`, обходя ограничения браузера на запись буфера из неактивных вкладок (`DOMException: Document is not focused`).
- **Многомониторные системы и DPI:** курсор позиционируется через `SetCursorPos` по абсолютным экранным координатам с человеческим джиттером $\pm 2..3$ px.
- **Старые лоты:** при открытии страницы все ранее найденные лоты помечаются как просмотренные (скрипт не кликает по старым вещам).
- **Спам лотов:** пока идет телепорт и выкуп одного предмета, все новые клики в браузере заблокированы.
- **Подмена предмета / скам:** если продавец выставил не ту вещь или подменил лот, бот сверяет имя предмета в памяти игры и прерывает покупку.
- **Загрузка вкладки продавца:** пока вкладка продавца подгружается, бот ожидает появления данных и не кликает по пустым элементам интерфейса.
- **Окно Confirm:** распознает и подтверждает модальные окна при дорогих покупках рекурсивно по дереву UI.
- **Таймаут «Уже продано»:** если окно магазина не открылось за 2.2 секунды, персонаж сразу возвращается домой.
- **Failsafe:** максимум 5 секунд в чужом хайдауте — при любом лаге персонаж гарантированно возвращается домой.
- **Обновление инстанса дома:** при возврате в убежище плагин автоматически перепривязывает хеш дома. Горячая клавиша **`F6`** позволяет в любой момент вручную задать домашнее убежище.

## ⚠️ Рекомендации перед запуском

1. Освободите место в инвентаре (минимум 6–8 свободных слотов).
2. Убедитесь, что в Kingsmarch (или в Stash) есть достаточный запас **Gold** на комиссию Фостуса.
3. Валюта для покупки может лежать как в инвентаре, так и в основных вкладках сундука (Currency Tab).

## 🛠 Установка

### 1. Браузер (Tampermonkey)
1. Установите расширение **Tampermonkey**.
2. Создайте новый скрипт и вставьте код из [`faustus_autobuyer.user.js`](faustus_autobuyer.user.js).
3. Нажмите `Ctrl + S`. На сайте трейда в правом верхнем углу появится плавающий виджет `Auto-Travel: АКТИВЕН`.

### 2. Игра (ExileApi)
1. Скопируйте папку `faustusbuyer` в папку `Plugins/Source/faustusbuyer` (или скомпилируйте `faustusbuyer.dll`).
2. В игре в меню ExileApi активируйте плагин `FaustusBuyer`.
3. Горячие клавиши:
   - **`F5`** — включить / выключить плагин.
   - **`F6`** — запомнить текущую зону как Дом (Hideout).
